# Wallr documentation

Wallr is a Wayland wallpaper engine for compositors implementing `wlr-layer-shell`. The normal pipeline is animation → wallpaper → optional theme provider → reload commands → hooks.

Quickstart:

```sh
wallr img ~/Pictures/forest.jpg
wallr doctor
```
